01 / 问题

三方都有痛，但没人把他们连起来

陌生人社交赛道很大，但男生觉得「假、套路、花钱没回应」，女生觉得「不安全、收入不透明」，线下陪玩店则「没流量、没工具」。痛点是彼此的解药。

男生：想有人真的陪

  • 传统交友 App 机器人、托号泛滥，付了钱没回应
  • 想视频、想见面，但没有安全可信的渠道和明确价格
  • 线下陪玩店信息不透明、体验靠运气

女生：时间值钱，但缺安全的变现方式

  • 陪聊、陪玩需求真实存在，但在微信、QQ 群里接单没保障
  • 收款、爽约、骚扰全靠自己扛，没有平台兜底
  • 缺乏持续曝光的渠道，收入不稳定

陪玩店：有人、有场地，没流量

  • 获客靠美团/抖音团购，抽成高、复购低
  • 陪玩师排班、订单、结算全靠人肉表格
  • 场地空闲时段大量浪费，线上变现为零

单位经济：一分钟视频通话

以 640×480@800kbps 双向流量实测，一分钟成本约 0.012 积分。女生定价 2 积分/分钟时：

男生支付2.00 积分
女生收入1.976 积分
平台抽成（成本 × 2）0.024 积分
流量成本0.012 积分

默认策略把绝大部分收入留给女生，用「女生赚得多」换供给侧的密度与活跃；倍率随规模逐步上调是后台一个数字的事。

05 / 线上 × 线下

线下是我们的护城河，也是流量来源

纯线上社交拼的是投放预算；我们把线下陪玩店变成「内容工厂 + 供给基地 + 履约场地」，用线下的真实感反哺线上的转化。

线下拍视频：内容工业化

每位认证女生每周产出 3 条 15–30 秒竖屏短视频，用于动态广场、抖音 / 快手 / 小红书 / 视频号投放，以及她的专属推广页。

  • 陪玩店包间改造为标准拍摄点：统一灯光、背景、机位
  • 三段式脚本：出场 3s → 技能 / 生活 10s → 一句邀请 + 下载引导 5s
  • 平台运营剪辑、统一片尾、批量分发，女生只需要出镜

平台推广：低成本获客矩阵

  • 短视频矩阵账号：每个城市一个官方号 + N 个女生号，内容来自线下拍摄
  • 专属推广页：每位用户一个网页（男版 / 女版），带 TA 的名片与下载链接，分享即拉新
  • 地推：高校、商圈、夜市、网吧、电竞酒店，扫码下载即用（无注册流失）
  • 老带新：邀请人获积分奖励，被邀请人首单折扣
  • 应用商店 ASO + TestFlight 灰度 → App Store 正式上架

线下陪玩店合作：从对手到基础设施

  • 店铺入驻为「认证机构」，陪玩师批量实名入驻，接线上视频与同城约单
  • 店内空闲包间成为视频通话点、拍摄点、线下约单履约点
  • 分成：店铺享受旗下陪玩师订单的一部分平台抽成，平台获得供给与场地
  • 店铺得到：免费的线上流量、排班 / 订单 / 结算工具、品牌联名
  • 首批目标：成都 3–5 家店，50–100 名陪玩师，作为模型验证

07 / 壁垒

为什么是我们

线上线下闭环，不是纯流量生意

线下陪玩店提供真实供给、履约场地和内容素材，线上提供流量和交易工具。竞品要么只做线上（拼预算），要么只做线下（没规模），闭环本身就是壁垒。

安全体系：实名 + 托管 + 仲裁 + 加密

搭子身份证实名、约单积分托管、纠纷平台仲裁、消息 AES-256 加密可双向清空。安全是女生愿意来的前提，也是合规的底线。

零门槛获客：一机一号

不要手机号、不要密码，安装即有账号，卸载重装自动恢复。地推与短视频引流的转化漏斗少了最漏的一层。

自建音视频，成本与能力都在自己手里

SRS 多节点调度已上线，后台增删节点、自动扩容、一键部署。相比云厂商 CPaaS 按分钟计费，成本低一个量级，且天然可扩展到直播 / 连麦 / PK。

AI 内容 + 热更新架构

花边新闻、励志行、AI 聊天等由 AI 每日生成，低成本提升留存；大厅模块 H5 化，小游戏、活动无需发版即可上线。

数据全在自己手里

用户、交易、通话、内容全部自有；平台账本逐笔可查，运营策略（分成、价格、可见性）后台实时可调，适合快速试错。
