# 心之音 UI 设计规范（已定稿：方案 A 玫红）

参考方向：抖音式暗色沉浸风。整体**纯黑沉浸 + 玫红渐变强调色**（#FE2C55 → #FF6B81）。

## 一、配色（已定稿 A）

| 方案 | 主背景 | 强调色 | 感觉 |
|---|---|---|---|
| A 玫红（推荐，最接近抖音） | #0A0A0C | 渐变 #FE2C55 → #FF6B81 | 年轻、社交、荷尔蒙 |
| B 香槟金 | #0A0A0C | 渐变 #E8C170 → #C9A063 | 豪华、稳重 |
| C 电光紫 | #0A0A0C | 渐变 #7C4DFF → #B388FF | 潮流、夜店感 |

通用色板（以方案 A 为例）：
- 背景层级：`#0A0A0C`（页面）/ `#161619`（卡片）/ `#212126`（输入框、次级卡片）
- 文字：主 `#FFFFFF`、次 `#8A8A93`、禁用 `#4A4A52`
- 分隔线：`#1F1F24`
- 强调：`#FE2C55`（按钮、选中态、红点、点赞）
- 成功 `#0BD07D`、警示 `#FFB800`、错误 `#FF4D4F`

## 二、底部导航（已定：抖音式）

- 纯文字五槽：**广场 · 大厅 · [+] · 消息 · 我的**
- 选中：白色 17px 加粗；未选中：#8A8A93 16px
- 中间 [+]：44x30 圆角 8 白色描边块，内白色加号；按下微缩动效
- 底栏纯黑 #000，无顶部分隔线，消息带红点数字

## 三、字体与间距

- 字体：系统默认（PingFang SC / SF Pro / Roboto），不引第三方字体
- 字号阶梯：22（页面大标题）/ 17（列表标题）/ 15（正文）/ 13（辅助）/ 11（角标）
- 间距单位 4pt 网格：页面左右边距 16，卡片内边距 14，卡片圆角 12，头像圆形
- 按钮：主按钮高 46 圆角 23（胶囊），强调色填充白字；次按钮透明底 1px #2A2A30 描边

## 四、页面规格

### 1. 广场（首页）
- 顶部：左"附近 | 推荐"切换（文字 tab，选中白粗+底部 3px 强调色短线），右上角"城市"选择
- **普通模式**：单列信息流卡片——头像+昵称+年龄标签行、正文、九宫格图/视频封面（圆角 8）、底部操作行（点赞 · 评论 · 打招呼），卡片间 8px 分隔
- **抖音模式**：右上角切换入口；全屏竖滑视频，右侧悬浮操作列（头像、点赞、评论、礼物，白色图形+数字），底部渐变遮罩上叠昵称与文案
- 双模式切换按钮固定顶栏右侧

### 2. 大厅
- 顶部横幅位（运营图，圆角 12，16:6）
- 模块网格：2 列卡片（后台下发），卡片=图标+名称+一句话说明，深灰卡片底，无描边，按下变亮
- 游戏模块上线后自动多一张卡片，排版不变

### 3. 发布页（+ 按钮进入）
- 全屏深色；顶部"取消 | 发布"（发布=强调色胶囊按钮）
- 文本框（占位"分享此刻…"）+ 九宫格加图（首格为加号虚线框）或单视频（选视频后显示封面+时长）
- 底部：城市定位行（可关）

### 4. 消息
- 会话列表：头像(48) + 昵称/最后一条消息预览 + 时间/未读红点
- 右上角"+"：发起群聊（选人建群）
- 聊天页：气泡——对方深灰 #212126 白字左侧，自己强调色白字右侧，圆角 18（尾角 4）；顶栏含 语音/视频通话、礼物 按钮
- 礼物面板：半屏底部弹层，礼物网格（图+名+积分价），底部余额+发送按钮

### 5. 我的
- 头部：大头像(72) + 昵称 + 地址缩写（0x12…89ab，可复制）+ 编辑资料入口
- 积分卡：余额大数字 + 冻结小字 + "明细 | 提现"两个文字按钮
- 功能列表行：我的动态 / 我的约单（男）· 我的接单（女）/ 地陪认证 / 收到的礼物 / 设置
- 行样式：左文字右浅灰箭头，行高 54，分隔线 #1F1F24

### 6. 找地陪 / 找人（大厅模块内）
- 顶部城市筛选 + "地陪 | 全部"切换
- 单列大卡：头像(56) + 昵称+年龄+地陪徽章（强调色小标签）+ 签名 + 相册三图横排 + 右侧"打招呼"胶囊小按钮

### 7. 约单
- 发布（男）：表单页——标题/时间(选择器)/城市+地点/报酬(积分)/补充说明，底部大按钮"托管发布"，附"报酬将冻结托管，完成后打给对方"说明行
- 接单大厅（女）：卡片列表——标题+报酬（强调色大字）+时间地点+报名数，点开详情报名
- 我的约单：状态标签色——待接单#FFB800 / 进行中#0BD07D / 已完成#8A8A93 / 已取消#4A4A52

### 8. 通话
- 视频：对方全屏，本地小窗右上(110x150 圆角 10 可拖动)，底部一排圆形操作（静音/挂断红/切换摄像头）
- 语音：中央大头像+昵称+计时，底部同款操作排
- 来电：全屏模糊头像背景，下方 接听(绿)/拒绝(红) 两圆钮

## 五、通用规则

- 全部矢量图标（线性 1.6pt 白/灰），禁止 emoji
- 空态：居中灰字一句话 + 次按钮引导，不放插画
- 加载：顶部细线进度或骨架屏（深灰闪烁块）
- 动效克制：页面切换系统默认，点赞心形缩放 0.2s，其余无动画
- Web 端同规范实现，最大宽 480 居中，两侧留黑
